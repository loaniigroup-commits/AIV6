# Daily Task Manager — Clean V2.1

Dark navy + gold Android task manager.

## Included
- Daily / Weekly / Monthly views and completion percentage
- Add, edit and view task details
- Separate task title and description
- Pending tasks automatically carry forward until Done or Cancel
- Smaller Done / Cancel controls
- Optional date + reminder time with local notifications
- Attachments: take a photo or choose a photo/file
- App-created photos saved under `Pictures/DailyTaskManager`
- Safe attachment deletion behavior
- EC logo launcher icon and branded splash screen
- GitHub Actions workflow included at `.github/workflows/android.yml`

## Build on GitHub
Create an empty repository and upload the CONTENTS of this folder, preserving folders. Commit to `main`. The included workflow will start automatically. When it finishes green, open the workflow run and download `DailyTaskManager-Clean-APK` from Artifacts, unzip it, then install `app-debug.apk` on Android.
